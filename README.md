# AI Writing Analyzer

AI Writing Analyzer is a web-based writing analysis dashboard
that evaluates measurable linguistic patterns and generates
an AI Writing Risk Score.

## Features

- Text analysis
- AI Writing Risk Score
- Vocabulary diversity analysis
- Sentence variation analysis
- Repetition analysis
- Writing pattern visualization
- Analysis history
- Responsive dashboard
- LocalStorage

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- LocalStorage

## Project Purpose

This project was developed to help students and lecturers
understand writing patterns through data-driven analysis.

## Disclaimer

The AI Writing Risk Score is an analytical estimate based on
textual patterns and should not be interpreted as definitive
proof of AI authorship.
